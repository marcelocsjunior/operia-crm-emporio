# SECURITY

## Diretrizes Básicas de Segurança

- Não versionar dados reais de clientes, leads ou negociações.
- Não versionar tokens, senhas, chaves privadas ou arquivos `.env`.
- Dados comerciais devem ser tratados como sensíveis.
- Vulnerabilidades identificadas devem ser tratadas internamente.

## Privacidade e Conformidade (Futuro)

- O produto deverá evoluir com preocupação contínua com LGPD.
- Políticas formais de tratamento, retenção e proteção de dados serão definidas nas fases técnicas futuras.
